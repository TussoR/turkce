# FP2級 MASTER

2級ファイナンシャル・プランニング技能検定（きんざい）の **学科試験** と **実技試験「生保顧客資産相談業務」** の学習アプリです。ビルド不要の静的Webアプリ（HTML＋ESモジュール）で、学習記録はブラウザの localStorage に保存されます。通信やAIを使わずに動きます（フォントのみGoogle Fontsを使用）。

## 起動
```bash
python -m http.server 8770 --directory fp2
# → http://localhost:8770
```
ESモジュールを使うため、`file://` で直接開くことはできません。

## 機能
| 画面 | 内容 |
|---|---|
| ダッシュボード | 総合進捗、学科・実技の推定得点と合格見込み（推定）、科目別の推定正答率、苦手科目、次に学ぶべきレッスン、復習予定 |
| 学習モード | 科目×難易度（入門〜試験レベル）のレッスン。用語・計算例・ひっかけ・確認テスト（8割以上で修了） |
| 問題演習 | 学科/実技・科目・論点・難易度・未解答/前回不正解/ブックマークで絞込み、弱点優先/ランダム、時間制限、即時採点と全選択肢の解説 |
| 実技試験対策 | 設例（顧客資料・表）を見ながら《問1〜3》を解く事例演習。〇×・語群選択・数値記入 |
| 模擬試験 | 学科（60問120分）・実技（5題15問90分）・総合。CBT風の画面、カウントダウン、見直しマーク、解答一覧、終了まで正誤非表示、自動採点、科目別分析 |
| 復習 | 間隔反復（翌日→3日→6日→…）。今日・期限切れ・苦手・定着済み・ブックマーク・科目別 |
| 弱点分析 | 論点別の推定正答率、繰り返す誤解（概念タグ）、計算問題の正答率、時間がかかる論点、未復習・未着手の論点 |
| 公式・数値集 | 税率・控除・年金額・法人保険の経理など。ひらがな/カタカナ検索、基準日と出典を表示 |
| 学習カレンダー | 試験日・1日の目標、学習履歴、残り日数と必要時間の見積り、自動学習計画 |
| 試験情報 | 公式に確認した試験制度（出典つき）、過去問分析の結果、公式の出題範囲 |

## 構成
```
fp2/
  index.html, css/app.css
  js/   main.js（ルーター）, core.js（問題バンク・記録）, store.js（保存）, srs.js（間隔反復）,
        analytics.js（推定・弱点）, qengine.js（出題形式・採点）, calc.js（FP計算ライブラリ）, util.js
  js/views/  画面ごとのモジュール
  data/ exam.js（公式情報）, analysis.js（過去問分析）, reference.js（数値と出典）, subjects.js（科目・論点）,
        q/（学科問題）, cases/（実技事例）, lessons/（レッスン）
  docs/ RESEARCH.md（調査報告）, CONTENT_GUIDE.md（問題作成ルールとデータ形式）
  tests/ validate.mjs（データ検証・計算問題の独立検算）, logic.mjs（計算・SRS・採点の単体テスト）
```

## 検証
```bash
cd fp2 && node tests/validate.mjs && node tests/logic.mjs
```
- `validate.mjs`：全問題のスキーマ、正答キーの整合（「最も適切/不適切」と解説の一致）、語群に正解があるか、計算問題を `js/calc.js` で独立に再計算して正答と一致するか、レッスンの参照整合性を検査します。
- `logic.mjs`：計算ライブラリ（公表問題の解答例と照合）、間隔反復、採点、模擬試験の出題構成（学科は各科目10問、実技は5領域×3問）と合格基準を検査します。

## 情報の区分
- **公式情報**：きんざい・国税庁・日本年金機構・厚生労働省などの公式ページで確認したもの（`data/exam.js`、`data/reference.js`）
- **過去問分析**：公表過去問の出題傾向を要約したもの（`data/analysis.js`）
- **オリジナル問題**：すべての問題・事例・レッスン（公式問題の転載はありません）
- **推定**：合格可能性、実技の配点（非公表のため均等配点と仮定）
