# コンテンツ作成ガイド（問題・事例・レッスン）

すべての問題・解説・レッスンは**自然で丁寧な日本語**で書く。対象は金融の専門家ではない社会人学習者。

## 絶対ルール
1. **オリジナルであること。** 公式過去問の文章・数値の組合せを転載しない。出題テーマ・形式・難易度を再現する。
2. **法令基準日 2026年4月1日** 現在の法令・数値に基づく。数値は `data/reference.js` と `docs/RESEARCH.md` の確認済みの値だけを使う。不明な数値（例：経過的加算の定額単価の2026年度値）は**問題の〈資料〉で与える**。
3. 令和8年度税制改正（基礎控除62万円・104万円、給与所得控除69万円など）は2026年12月1日施行のため基準日時点では未施行。**所得税の計算問題では基礎控除・給与所得控除の額や速算表を資料・問題文に明記する**（例：「基礎控除の額は58万円とする」）。基礎控除の金額そのものを問う知識問題は作らない。
4. 教育資金一括贈与は2026年3月31日で終了。在職老齢年金の支給停止調整額は2026年度65万円。老人扶養48万円・同居老親等58万円。高額療養費は基準日時点の算式（80,100円＋(医療費−267,000円)×1%）。
5. 正解は必ず1つ。四択の「最も不適切」「最も適切」を混在させる（学科は不適切 6：適切 4 程度）。
6. 計算問題には `steps`（手順）と `verify`（検算式）を必ずつける。
7. 誤答の選択肢には、実際の試験で繰り返されるひっかけ（`data/analysis.js` 参照）を使う。各選択肢に `why` で理由を書く。

## ファイル
- 学科問題：`data/q/<科目id>.js` → `export default [ ... ]`
- 実技事例：`data/cases/<領域id>.js` → `export default [ ... ]`
- レッスン：`data/lessons/<科目id>.js` → `export default [ ... ]`
- 科目・論点 id は `data/subjects.js`

## 学科問題（四肢択一）
```js
{
  id: 'lp-012',              // 科目id-連番3桁（ファイル内で一意）
  topic: 'lp.nenkin',        // subjects.js の論点id
  level: 3,                  // 1入門 2基礎 3標準 4応用 5試験レベル
  type: 'mc',
  stem: '公的年金の老齢給付に関する次の記述のうち、最も不適切なものはどれか。',
  choices: ['…', '…', '…', '…'],   // 4つ
  answer: 2,                 // 0始まり
  why: ['適切。…', '適切。…', '不適切。正しくは…', '適切。…'],  // 各選択肢の理由
  explain: '全体の解説（要点。2〜4文）',
  tags: ['繰上げ・繰下げ'],   // 誤解しやすい概念のタグ（短い名詞句。同じ概念は同じ表記で）
  trap: '任意：ひっかけの注意書き',
  calc: true,                // 計算問題のみ
  steps: ['手順1', '手順2'],  // 計算問題のみ
  verify: [{ expr: 'incomeTax(5000000)', value: 572500 }], // 計算問題：正解の数値を独立に再計算
  origin: 'analysis',        // 過去問分析に基づくオリジナル
}
```
- 計算の四択では、`value` の数値を `toLocaleString('ja-JP')` で書いた文字列（例：`572,500`）が正解の選択肢に含まれていること（検証スクリプトが確認する）。万円単位で出す場合は `value` も万円で書き、`unit: '万円'` をつける。

## 実技事例（生保顧客資産相談業務）
本試験と同じ形式：1事例＝設例＋《問1》〜《問3》。形式は `tf`（〇×）、`blank`（語群選択）、`num`（数値記入）のみ（三肢択一は出題されていない）。
```js
{
  id: 'jn-01', subject: 'jn', level: 5,
  title: '会社員Aさんの老後の年金と働き方',
  theme: '老齢年金の計算・繰下げ・在職老齢年金',
  doc: [  // 設例
    { p: '会社員のAさん（58歳）は…FPのMさんに相談することにした。' },
    { h: '〈Aさんとその家族に関する資料〉' },
    { ul: ['Aさん：1968年5月10日生まれ', '…'] },
    { table: { head: ['…'], rows: [['…']] } },
    { note: '※ 妻Bさんは、現在および将来においても、Aさんと同居し、生計維持関係にあるものとする。' },
  ],
  questions: [
    { id: 'jn-01-1', topic: 'jn.rorei', type: 'num',
      stem: 'Mさんは、Aさんが65歳から受給できる…を試算した。〈資料〉を利用し、空欄①〜③に入る最も適切な数値を求めなさい。\n〈資料〉…',
      parts: [{ label: '①', a: 847300, unit: '円' }, { label: '②', a: 1234567, unit: '円' }],
      steps: ['…'], explain: '…', tags: ['…'],
      verify: [{ part: 0, expr: 'oldAgeBasic(847300, 480)' }, { part: 1, expr: '...' }] },
    { id: 'jn-01-2', topic: 'jn.kuriage', type: 'tf',
      stem: 'Mさんは、Aさんに対して…説明した。Mさんが説明した次の記述①〜③について、適切なものには〇を、不適切なものには×を選びなさい。',
      items: [{ s: '…', a: true, e: '理由' }, { s: '…', a: false, e: '理由（正しくは…）' }, { s: '…', a: true, e: '…' }],
      explain: '…', tags: ['…'] },
    { id: 'jn-01-3', topic: 'jn.shaho', type: 'blank',
      stem: '…〔①〕…〔②〕…〔③〕…\n文中の空欄①〜③に入る最も適切な語句または数値を、下記の〈語句群〉のなかから選びなさい。',
      blanks: [{ k: '①', a: '93日' }, { k: '②', a: '67%' }, { k: '③', a: '3回' }],
      bank: ['30日', '93日', '180日', '50%', '67%', '80%', '2回', '3回', '5回'],
      explain: '…', tags: ['…'] },
  ],
}
```
- 問題文中の空欄は全角の亀甲かっこ `〔①〕` で書く（画面で下線つき空欄として表示される）。
- `num` の各 `parts[i].a` は整数（円）。`verify` は `part` 番号ごとに独立した式で検算する。
- 設例の数値は全問で整合させる（年齢・生年月日・加入月数など）。
- 第1問=jn（年金）、第2問=jk（個人保険）、第3問=jh（法人保険・退職金）、第4問=js（所得税）、第5問=jz（相続）。

## 検算式（verify.expr）で使える関数（`js/calc.js`）
`incomeTax(課税所得)`, `salaryDeduction(収入)`, `salaryIncome(収入)`, `retirementDeduction(年数)`, `retirementIncome(収入, 年数, {officerShort})`, `temporaryIncome(収入, 支出)`, `lifeInsDeductionNew(保険料)`, `lifeInsDeductionOld(保険料)`, `oldAgeBasic(満額, 納付月数)`, `earningsRelated(平均標準報酬月額, 月数, 平均標準報酬額, 月数)`, `survivorEmployees(報酬比例部分, 月数)`, `deferFactor(月数)`, `earlyFactor(月数)`, `inheritanceBasicDeduction(人数)`, `insuranceExempt(人数)`, `inheritanceTaxTotal(課税遺産総額, [法定相続分...])`, `inheritanceTaxOnPart(取得金額)`, `giftTax(贈与額, 特例税率?)`, `seisanGiftTax(基礎控除後の額, 既使用特別控除)`, `officerRetirement(最終報酬月額, 年数, 倍率)`, `highCostCareU(医療費)`, `sicknessAllowanceDaily(標準報酬月額平均)`, 係数 `fvFactor, pvFactor, crf, sinkingFund, annuityFV, annuityPV`, `ownerYield(利率, 購入価格, 売却価格, 年数)`, `yieldSimple(利率, 価格, 残存年数)`, `Math.*`。式はJavaScript。

## レッスン
```js
{
  id: 'lp-l01', subject: 'lp', exam: 'gakka', level: 1, minutes: 15,
  title: '公的年金のしくみ（入門）',
  topics: ['lp.nenkin'],               // 関連する論点id
  intro: 'このレッスンで学ぶこと（2〜3文）',
  body: [
    { h: '1. 公的年金は「2階建て」' },
    { p: '本文。<ruby>被保険者<rt>ひほけんしゃ</rt></ruby>のように難語にふりがな可。**強調**可。' },
    { ul: ['…'] },
    { table: { head: ['…'], rows: [['…']] } },
    { formula: '老齢基礎年金 ＝ 満額 × 納付月数 ÷ 480' },
    { example: { title: '…', given: '条件', steps: ['…'], answer: '…' } },
    { point: '覚えるポイント' },
    { trap: '試験でのひっかけ' },
  ],
  terms: [['被保険者', 'ひほけんしゃ', '保険の対象となる人。…']],   // [用語, 読み(不要なら''), 説明]
  traps: ['…'],
  quiz: ['lp-001', 'lp-002', 'lp-003', 'lp-004'],   // 確認テスト：同じ科目の問題id（4〜6問、レッスンの内容で解けるもの）
  refs: ['pen-basic'],                               // reference.js の id
}
```
- 各科目のレッスンは 入門(1) → 基礎(2) → 標準(3) → 応用(4) → 試験レベル(5) の順に並べる。
- 身近な具体例（家族構成・金額）と、計算例を必ず入れる。表を積極的に使う。
- 1レッスン＝本文で800〜2,000字程度。
